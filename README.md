# Antibiose - Protótipo para Disciplina de Desenvolvimento de Jogos

_Antibiose_ é um DomeKeeper-like onde você deve proteger o núcleo da floresta dos _decompositores_!

## Contexto

Este projeto é parte do material didático para a disciplina de Desenvolvimento
de Jogos do curso de Sistemas de Informação da EACH-USP. Inspirado em _Doom
Keeper_, o jogador deve proteger o coração da floresta, coletar recursos,
enfrentar hordas de inimigos enquanto busca uma maneira de ganhar o jogo
e salvar a floresta.
